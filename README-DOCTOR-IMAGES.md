## Important Naming Rules

- Use lowercase filenames exactly as shown.
- Do not add a second extension. Use `dr-srihari.jpg`, not `dr-srihari.jpg.jpg`.
- Keep the files directly inside `images`, not inside another subfolder.
- Use clear portrait photos with the doctor's face near the top center.
- JPG is preferred. If you use PNG, rename the file to `.jpg` only after converting it properly; do not simply change the extension.
- `dr-srihari.jpg` is used both in the homepage Managing Director card and the Doctors section.

## Recommended Photo Size

- Portrait ratio: approximately 4:5.
- Recommended size: 800 x 1000 pixels or larger.
- Keep the face and shoulders visible with some space above the head.

## Missing Photos

If a matching file is not present, the website shows the doctor's initials instead. Once the correctly named image is placed in `images`, refresh the page with `Ctrl + F5` to view it.
